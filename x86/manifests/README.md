# Manifestos e Configurações: Instâncias x86

Este diretório é destinado aos manifestos, arquivos de configuração adicionais e definições de serviços para as instâncias x86:
- **`vault`**: Arquivos de políticas de acesso, templates de configuração de cluster, e scripts de inicialização unseal/init.
- **`vpn`**: Perfis de conexão WireGuard/OpenVPN, arquivos de rotas seguras e chaves públicas de clientes.
